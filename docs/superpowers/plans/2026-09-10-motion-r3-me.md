# R3 — Me as "Mi semana" Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `/me` reorders into "Mi semana": an identity header with the one line that matters («Te toca el domingo 13 · Lead» with a countdown), the member's own services (the next in full, the rest collapsed), availability as a weekend list with the month grid behind a disclosure, and one Ajustes card holding Tema, Tamaño de texto and the profile.

**Architecture:** `AvailabilityCalendar`'s state and save machinery (revision-guarded PATCH, the one-time sibling rebase, the held conflict) move verbatim into a hook, `useAvailability`; two surfaces render it — `WeekendList` (default) and `AvailabilityGrid` (the existing grid, unchanged, behind `Collapse`). The identity line comes from a neutral helper over the page's already-computed assignments. Reuse: `NextServiceHero`, `DayCardDisclosure` (R1), `daysUntil`/`formatCountdown`, `NumberRoll`, `Presence`, `Collapse`, `Button`, `useToast`, `SegmentedControl`, `Switch`.

**Tech Stack:** Next.js 16 App Router, React 19, Tailwind 3.4, `motion` 13.2 (via `ui/` primitives only), vitest + RTL, Node 22.

**Spec:** `docs/superpowers/specs/2026-09-08-premium-motion-design.md` §12.4 (Mi semana), §5.6 (`/me` motion), §18 (label budget), §19.2, Part IV decision I (weekend list, grid behind a disclosure). Deferred: R7 items.
